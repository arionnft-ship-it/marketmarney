# Marney 4.25 Light Only

Versi ini menggunakan satu tampilan terang untuk seluruh antarmuka aplikasi.

## Perubahan

- Menu bawah, status bar, navigation bar, layar pemulihan, dan opening aplikasi selalu terang.
- Beranda, Berita, Market Live, Analisa, Kalender, Watchlist, Utilities, TV, Social Marney, Grup, Profil, Akun, dan Jurnal dipaksa memakai tema terang.
- Reels tetap menampilkan video secara penuh, tetapi toolbar, tombol, panel opsi, status, dan navigasi menggunakan permukaan terang.
- Pilihan tema gelap disembunyikan dan perubahan ke tema gelap dari preferensi lama otomatis dikembalikan ke terang.
- Preferensi tema lama di perangkat diubah menjadi `light` ketika halaman aplikasi dibuka.
- Unggah foto dan video tetap langsung membuka galeri Android seperti versi 4.24.
- Logo transparan, tampilan 3D ringan, dan penyederhanaan Beranda tetap dipertahankan.

Warna asli di dalam foto, video, grafik pihak ketiga, atau arena 3D dapat tetap memiliki bagian gelap karena merupakan isi media, bukan tema antarmuka.

## Memasang

1. Unduh `Marney425.apk`.
2. Pasang dan buka **Marney 4.25 Light**.
3. Masuk kembali bila diminta.

Paket beta: `com.marketmarney.mobile.beta425`, versi `4.25.0-beta`, kode 29. Paket ini dapat terpasang berdampingan dengan 4.24 sehingga sesi login lama tidak otomatis berpindah.

## Pemeriksaan

Build memeriksa tanda tangan APK, identitas paket, inventaris aset, penerapan tema terang, penghapusan kontrol tema gelap, Reels terang, navigasi, galeri langsung, layar pemulihan, dan runtime Android pada emulator API 35.
